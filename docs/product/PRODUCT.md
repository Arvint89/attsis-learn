# PRODUCT — Attsis Learn

## What we build
A GitHub Pages landing page that converts parent visits into WhatsApp inquiries for the Attsis Learn robotics and engineering programme.

## Who buys it
Parents of children ages 6–14 in London, Ontario seeking hands-on STEM education with a credentialed instructor.

## The programme
| | Level 1 | Level 2 |
|---|---|---|
| Ages | 6–9 | 10–14 |
| Sessions | 8 | 8 |
| Focus | Block-based robotics | Arduino + electronics |
| Output | Rolling robot | Self-designed project |
| Cert | Yes | Yes |

## Instructor credentials
- Licensed P.Eng (Professional Engineer)
- VSC (Vulnerable Sector Check) cleared
- Hands-on teaching methodology — no passive instruction

## Funnel
1. Parent finds site (Google / referral / social)
2. Reads course cards + trust bar
3. Clicks WhatsApp CTA → free session inquiry
4. BT books free session → enrolment conversation

## Revenue model
Pricing on inquiry. No public prices. No booking form. WhatsApp only.

## Future products
- Level 1 session workbook → KDP/Etsy PDF (`content/level1/`)
- Level 2 session workbook → KDP/Etsy PDF (`content/level2/`)
