# Session 06 — Problem Solvers

## Learning objective
Students apply the engineering design process (Define → Ideate → Build → Test → Improve) to a structured mini-challenge.

## Key concepts
- Engineering design process: 5 steps
- Constraints: rules that limit what you can build
- Iteration: the first try is never the last try

## Mini-challenge
**Mission:** Program your robot to carry a small object from point A to point B without dropping it, in under 30 seconds.

**Constraints:**
- Cannot touch the robot once started
- Object must stay on robot the entire trip
- Time limit: 30 seconds

## Activities
1. **Design process intro** (10 min) — poster walkthrough of the 5 steps; real engineering examples
2. **Define + Ideate** (10 min) — pairs write down their plan before touching the robot
3. **Build + Test** (25 min) — open build and code time; instructor circulates with questions, not answers
4. **Improve + Share** (15 min) — one iteration pass; each pair shares what changed and why

## Instructor notes
Resist giving answers. Ask: "What did the test show you? What would you change?" This session builds engineering instinct.
