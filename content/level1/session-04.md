# Session 04 — Follow My Commands

## Learning objective
Students write their first program using block-based programming, understanding that a program is a precise sequence of instructions.

## Key concepts
- Sequence — order matters; computers do exactly what you say
- Block-based coding: drag, snap, run
- Move forward, turn, wait as basic blocks
- Debugging: why the robot didn't do what you expected

## Activities
1. **Human robot** (10 min) — instructor is the robot; students give verbal commands; instructor follows literally (walks into wall if told to)
2. **Block intro** (10 min) — tour of the programming interface; blocks explained one by one
3. **Code your square** (25 min) — students write the square program themselves from scratch
4. **Debug challenge** (15 min) — instructor introduces a bug; students find and fix it

## Materials
- Laptop or tablet per pair (programming interface open)
- Pre-built robot from previous sessions

## Instructor notes
The "human robot" activity is critical — it makes the concept of literal instruction concrete before any screen time.
