# Session 05 — Robot Eyes

## Learning objective
Students attach a sensor to the robot, read sensor data in the program, and write their first reactive (if/then) behaviour.

## Key concepts
- Sensor types: touch (button), light, distance (ultrasonic)
- Reactive behaviour: if [sensor] detects [condition] then [action]
- The if/then block in the programming interface

## Activities
1. **Sensor exploration** (10 min) — students hold each sensor type and trigger it; read live values on screen
2. **Attach the distance sensor** (10 min) — guided wiring of ultrasonic sensor to the front of the robot
3. **Obstacle avoider** (30 min) — students write: if distance < 20 cm → stop + turn; test on a box obstacle course
4. **Show and tell** (10 min) — each pair demos their robot avoiding obstacles

## Materials
- Ultrasonic distance sensor (1 per robot)
- Cardboard box obstacle course

## Instructor notes
Expect wide variation in sensor threshold values per robot — let students tune their own. This is real engineering.
