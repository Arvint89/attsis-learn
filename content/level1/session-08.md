# Session 08 — Robot Showcase

## Learning objective
Students present their robot to the class, explain what it does and how they built it, and receive their certificate of completion.

## Format
Demo day. Each pair presents for 3–4 minutes. Parents are welcome to attend.

## Presentation prompts (students answer)
1. What challenge did you choose and why?
2. What does your robot do?
3. What was the hardest part?
4. What would you change if you had one more session?

## Session structure
1. **Setup + final test run** (10 min) — pairs get one last run before presenting
2. **Presentations** (35 min) — each pair demos live; class asks one question each
3. **Certificates** (10 min) — instructor presents certificates; group photo
4. **What's next** (5 min) — brief intro to Level 2 for interested students

## Instructor notes
Print certificates before session. Invite parents if possible — it significantly increases re-enrolment and referrals.

## Certificate text
*[Student Name] has successfully completed Attsis Learn Level 1 — Junior Engineer Programme. Awarded by [Instructor Name], P.Eng.*
