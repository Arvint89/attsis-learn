# Session 07 — Design Challenge: Build Sprint 1

## Learning objective
Students apply the full engineering design process to an open-ended project of their choosing, completing hardware assembly and core code by end of session.

## Format
Open project session. Each student (or pair) works on their individual project. Instructor acts as consulting engineer — available for questions, not giving answers.

## Project options (or propose your own)
- **Smart home sensor** — monitors temperature, light, and motion; logs to Serial; triggers alerts
- **Obstacle-avoidance rover** — autonomous robot using ultrasonic sensor + two motors
- **Reaction time game** — LED lights randomly; player presses button; system measures and displays response time
- **Plant watering alert** — soil moisture sensor triggers LED + buzzer when plant is dry
- **Binary calculator** — input two 4-bit numbers via DIP switches; output sum on LED display

## Session structure
1. **Project proposal** (10 min) — student writes: what it does, what sensors/actuators, what the hardest part will be
2. **Schematic drawing** (10 min) — circuit on paper before touching hardware; instructor approves before build
3. **Hardware assembly** (25 min) — build and wire the circuit
4. **Core code** (30 min) — write the main logic; must compile and run basic version by end of session

## Instructor notes
Require the schematic approval step — no skipping. Students who skip it spend 20 minutes debugging wiring they drew wrong in their head.
